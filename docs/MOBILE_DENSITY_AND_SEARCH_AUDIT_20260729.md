# 移动端快速接单与全站搜索框审计报告（2026-07-29）

## 结论

本次问题不是单一的“字体太大”，而是五类布局规则叠加：

1. 快速接单字段把 `44px` 的真实输入再次包进上下内边距，视觉高度接近 `52–58px`。
2. 常见维修项目固定三列时，每格又保留独立 `44px` 下拉区域，标签只剩一个汉字。根据老板确认，本轮保留三列结构，只缩小内部图标、间距和细分按钮比例，并为四个长名称提供可辨识短标签。
3. 移动底栏采用固定定位，正文却用固定 `9rem/12rem` 猜测让位高度；状态文案、安全区或浏览器工具栏变化后会遮挡末尾内容。
4. 搜索框存在 standalone 与 embedded 使用不一致、部分入口仍为 `40px/14px`，以及有框父容器内再次绘制搜索边框的“框中框”。
5. “工单设置”的录入人员使用内置标签的 40px 卡片，而随附物品、类型、状态使用外置标签的 44px 控件；虽然外层是两列，标签基线、控件高度和圆角不一致，形成“一大一小”的错觉。

移动端不能通过把输入字体缩小到 16px 以下解决，否则 iOS Safari 会自动放大页面；触控目标也不能小于 44px。正确做法是保留输入和触控尺寸，压缩重复 padding、重复边界和非交互说明。

审计基线为 `origin/main@9652c710`。`src/routes/*` 是非活跃遗留路由，不计入 App Router 的活跃入口。

## 已实施的共享修复

### 1. 搜索外壳统一

- `repairOs.searchBar`：只用于父级没有完整边框的独立搜索。
- `repairOs.searchBarEmbedded`：用于 Floating Card、卡片、Drawer、Popover 等已有边界的父级。
- `RepairOsListScaffold` 位于 Floating Card 内，因此默认改为 embedded；仍允许显式传入 standalone。
- 搜索输入保持 `min-w-0`，扫码/筛选等尾部动作由共享网格保证最小 44×44px。

### 2. 移动输入统一

- 手机真实输入字号保持 16px，避免 iOS Safari 自动缩放。
- 移动搜索和关键可编辑控件保持 44px；桌面在 `lg` 后可收紧到 36px/14px。
- placeholder 只承担视觉提示，完整搜索范围继续通过 aria-label 提供。

### 3. 快速接单密度统一

- 手机维修分类保持原三列；只调整格内比例和长名称视觉短标签，不改变选择与细分交互。
- 字段外壳只承担单一边界，不再给 44px 输入重复增加上下高度。
- 固定底栏保持原来的“保管摘要在上、主 CTA 在下”结构，只收紧间距；实际高度由测量值同步给正文。
- 工单设置继续使用“保修整行、录入人员/随附物品双列、类型/状态双列”；两列显式为 `minmax(0, 1fr)` 等分，标签和控件使用同一基线与 44px 视觉高度，长录入人员名称只在控件内部截断，不再改变列宽。

## 后续修复计划

以下项目不影响本轮移动端共享根因修复，但需要作为下一切片完成：

1. 将客户、库存、回收、工单桌面 framed toolbar 的搜索输入迁移为 embedded，删除内部持久边框和 card shadow。
2. 将设置导航、成员、供应商搜索迁移为 embedded；保持现有 44px 移动命中区。
3. 抽取统一 SearchField 接口，明确 `standalone | embedded`、视觉 placeholder 与独立 aria-label，禁止页面继续手写高度和边界。
4. 增加可执行的页面矩阵测试，至少覆盖 `/orders`、`/customers`、`/inventory`、`/buyback`、`/messages`、`/memos`、`/settings` 的 320/390/440px。
5. 在真实 iOS Safari 验证软键盘、visual viewport、页面 scale=1；桌面 Playwright WebKit 不能代替这项证据。

## 验收标准

- 320、360、375、390、430、440px 下无页面横向溢出。
- 快速接单 12 个维修分类均能直接区分，不出现单字加省略号。
- 手机可编辑输入 computed font-size 不低于 16px。
- 手机主要按钮、搜索尾部动作和下拉触发器不小于 44×44px。
- 最后一个字段可完整滚到底栏上方至少 8px；状态文案增高时正文让位同步更新。
- Floating Card 内搜索只有一个持久边界；内部 Input 不再形成第二/第三层边框。
- 搜索查询、清除、扫码、筛选、客户匹配和建单 payload 语义不变。
- 工单设置第二、第三行左右列宽差不超过 1px，同一行顶部坐标差不超过 1px，录入人员与随附物品控件均为 44px；原字段顺序和建单语义不变。
