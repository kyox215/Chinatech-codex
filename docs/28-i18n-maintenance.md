# 三语维护与关联闭环

后续任何功能新增、修复或文案调整，都须同时提供中文、意大利语和英语，并验证受影响的业务关联。中文是消息键；字典条目按 `[意大利语, 英语]` 排列，不能颠倒。仅声明规则不等于完成验收。

- 页面标题、字段、选项、状态、加载／空态／无权限、校验和错误、操作反馈、图片 alt 与 aria 名称均属用户可见内容。有限配置和动态拼接也要检查，不能只统计直接 `t` 调用。
- 普通固定文案使用 `t`；动态系统错误使用 `systemText`，仅匹配已审核完整句式。字段名按有限字段集合翻译；错误中的客户／配件名称保持原文。新增句式必须补三语与正反例。
- 预设选项分离显示标签与 canonical 值。语言切换不能触发业务写入、改数量／金额、重写自由姓名／备注或冻结签名、销售及政策快照。`SearchCombobox.displaySelectedLabel` 只影响展示；选择和验证仍使用 canonical 值。
- 可搜索的预设分类／状态／颜色等须匹配三语显示标签，别名只加入查询索引；原始值、数量／分页及筛选规则不变。复合配件规格按有限结构逐项翻译，不依赖未审核的整段字符串兜底。
- 缺值占位由数据是否缺失判断，不能把与字典相同的真实姓名当成占位。结构化故障与补充原文分开显示；维修目录只增加投影元数据，保存对象保持原值。
- 依受影响事实核对新建／编辑→校验→明确保存→共享列表与详情→刷新恢复→客户及原记录回链→适用历史／签名／打印／教程。取消不写、失败保留输入、冲突需核对；无关模块不机械扩展。
- 三语的长词／按钮不能叠压、逐字竖排或被固定宽度挤碎。复用现有控件、token 和两套主布局，不靠缩小字号或隐藏事实处理。
- 教程改变画面时重新测量真实 DOM 鼠标落点，三语同步重拍与媒体校验。公开讲稿没变时复用已有配音，网页运行不调用语音服务；演示只使用本机虚构数据。

发布检查包含 `npm run check:i18n`、lint、严格类型、相关业务与浏览器测试及 build。CI 自动拒绝缺译、错位数组、变量／数字约束不匹配、同键冲突和未包装的固定可见文案。`node scripts/check-i18n.mjs --json` 提供动态边界与逐项例外；任何例外必须指出原始事实或独立语言系统的具体来源。

AST 不能证明任意运行时返回、跨模块数据流或未知数据库原文。还须按受影响页面和状态实际检查中文／意大利语／英语；公共 UI 按 1440、1024、390、375 核对，额外宽度只在确证问题需要时增加。正式与预览、实体与模拟、打印预览与实体打印的证据分开记录。
