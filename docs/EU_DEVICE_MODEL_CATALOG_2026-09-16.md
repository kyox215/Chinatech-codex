# 欧洲维修设备型号目录 · 2026-09-16

本轮首版：**970 个官方可追溯名称条目**，其中 **748 个有官方硬件代码**、**424 个有至少一个欧洲代码依据**；另列 **49 个待核实候选**。覆盖20个品牌组（Nokia/HMD、Nothing/CMF、ZTE/nubia合组）。这是维修选项资料，不代表欧洲全部机型或销量排名。

## 阅读规则

- `official_europe_code_verified`：欧洲列中的代码有官方欧洲支持/声明/产品页，或官方明确覆盖欧洲的地区组。欧洲包括UK；UK证据不等于EU27。
- `official_code_region_unverified`：名称和硬件代码关系有官方依据，但未证明欧洲版归属。
- `official_name_only`：仅名称有官方依据，硬件代码为空，不能当成已核验代码使用。
- 全球代码列保留来源列出的地区变体；欧洲代码列是其中已单独获得欧洲依据的子集。空白不是不存在。
- `A135F` 是 `SM-A135F` 的检索别名；`/DS`、`/DSN` 仅在官方明确出现时保留。别名归一化不能制造地区后缀。
- 同一个硬件代码可对应多个营销名称（例如Pro/Ultimate、F/FS）；选择器须保留歧义，禁止强行一对一。
- Apple旧机型与iPad未明确区分欧洲的代码不凭经验填写欧洲列；JSON保留官方地区事实。

## 已知缺口与冲突

- Motorola主要为墨西哥官方映射，只有单独UKCA证据进入欧洲列；vivo、TCL、ZTE、HONOR、Huawei、Nothing仍有较大代码缺口。
- Samsung Knox是全球兼容目录，含多地区版本；以官方搜索索引读取，未声称所有代码是欧版。SM-N985F的5G标签冲突已隔离。德国支持页Z Flip7/Fold7/Flip7 FE行出现互换，未采用这些错误行，使用官方LCA的EU/UK映射。该页A10的SM-105F缺字也未采用。
- 小米官方索引的Redmi Note 9下载指向M2007J22G，疑似名称错配，未采用。PDF扫描件和未读取声明只确认名称。
- 现有项目中的“iPhone 17 Air”不是本轮Apple官方识别页名称；官方名称为iPhone Air。候选保留便于后续人工处理。
- 2016年以来常修机型是主要范围，但来源没有年份的记录不伪造年份；大部分旧平板、运营商专版和硬件修订仍未穷尽。
- 自动提取脚本最后一次重读小米文件遭DNS失败；已成功读取的代码事实在构建脚本中明确固定，失败不会被当成新增证据。
