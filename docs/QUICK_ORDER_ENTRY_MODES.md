# 快速接单双模式

快速接单支持店铺级 `professional`（专业模式）和 `simple`（简易模式）：

- 专业模式保持原有全部字段、三栏布局和创建链路，是数据库与应用的默认值。
- 简易模式把同一个接单表单分成客户资料、设备与交接、维修与报价、确认创建四步。只有第四步可以提交。
- 两种模式共享客户身份确认、设备解锁、成本、离线草稿、`operation_id`、创建 API 和成功跳转；切换呈现方式不会建立第二套业务链路。
- 接单会话会锁定打开时的店铺和模式。设置变更只影响下一次打开；填写期间切换店铺会冻结当前会话，防止跨店提交。
- 解锁内容不会出现在确认摘要或离线草稿中。

## 发布顺序

1. 审查并应用 `store_settings.new_order_entry_mode` migration。
2. 部署兼容版本，保持 `NEXT_PUBLIC_REPAIRDESK_NEW_ORDER_SIMPLE_MODE_ENABLED=0`。
3. 完成试点验证后，把构建变量设为 `1` 并重新构建、部署。
4. 在“设置 → 规则 → 快速接单模式”中把指定店铺改为简易模式。

关闭构建变量或把店铺设置恢复为专业模式即可回退用户界面；不要删除已发布的数据库列，也不要改写已应用 migration。

设备未留店时，客户端状态选项、最终表单校验和服务端创建链路都会拒绝需要门店保管设备的诊断、维修或取机状态。
