# 全站共享品牌型号目录

## 2026-10-13 三级选择与读取提速

品牌、系列、型号在同一个选择面板连续完成，型号明确选定后才更新新建表单；取消、返回或关闭不写入部分选择。桌面锚定当前字段，手机使用底部选择面板；名称、机型码与别名在当前系列索引中搜索，候选按目录ID区分，长列表只渲染可见窗口，不用分页按钮。商品品牌仍允许按原规则不记录；未知系列与型号有手填路径。就地编辑只改当前字段：品牌编辑不连带改型号，型号编辑固定当前品牌。系列是界面导航，不保存为实物或销售事实。

`GET /api/catalog?kind=picker-index` 预取当前类别的启用精简参考索引，维修“电脑”包含笔记本与台式机。返回版本、格式和本次授权作用域；最多3000型号，超过时完整返回分组但不返回截断型号，按品牌／系列细化。`familyExact=1` 区分未筛系列与明确空系列，超大系列由原模型查询按需读取。普通目录管理列表继续分页；“全部类别”品牌候选覆盖全部目录类别。

正式GET保留Auth与项目会话、门店、成员、目录权限检查，合并到一笔原受限事务；账号管理和目录写入路径继续保留原权限／幂等／历史规则。候选缓存只在当前文档内，绑定会话、门店、成员版本、后台代际、格式与目录版本；重新授权前不可确认旧候选，401／403／409及身份变化清理全部投影，旧请求不得回填。聚焦／联网／手动刷新和可见页面30秒版本核验重新查询；同版本仅返回小响应，发现新版本使其他类别缓存失效。响应保持private/no-store，不使用公共CDN缓存、持久权限缓存或种子替代正式目录。

原品牌型号长度、手填原文、草稿恢复、维修服务与报价关联、签名失配、商品检测重置和冻结打印快照沿原领域规则。只读选择不会自动推断网络、RAM、电池或其他实测事实。最终发布与当前验证记录见PROJECT_MEMORY；本轮证据在`.local/device-catalog/picker-*`。

商品新建、同型号新建后的选择、商品就地编辑和维修接机品牌／型号从同一 `/api/catalog` 读取。电脑维修原有“电脑”值继续保留，候选同时覆盖笔记本与台式机；整机商品仍按原六类别区分。目录是型号参考，不能代表客户设备或门店自有实物，也不自动带入 RAM、磁盘、电池、检测、颜色、IMEI 或成本。

正式权威是 `chinatech_v2_private.device_catalog_entries`。版本与指定全站管理员在独立 control 行；历史和请求回执分别保存。普通获授权门店成员能查看启用条目、搜索代码与品牌别名，也能手填未知原文。老板或管理员角色本身不取得全站目录维护权限。指定账号仍需有效账号、项目会话及门店成员范围。管理员账号绑定由操作者在受控数据库维护中完成，应用运行角色没有该列的更新权限。

目录管理列表最多每页50条，计数和搜索覆盖全部获授权目录。新建商品与维修接机依次选择品牌、系列、型号；当前系列可搜索完整型号或代码，未知系列支持手填。按已证明的日期／年份降序，缺失日期留空并排在后面，同组按自然名称降序。品牌别名只用于查询；Redmi／红米合并，Xiaomi、POCO保持不同品牌。网络和硬件版本分行，A13的 SM-A135／SM-A137／SM-A136不得合并。电脑按系列、代际、官方机型码维护，不排列 RAM／SSD 配置 SKU。

维护入口位于账号菜单的“设备目录”，不新增业务模块导航。单项编辑及 Excel 导入都先预览，管理员再确认应用。导入文件最长4MB、最多10000行，服务端拒绝宏、公式、外部工作表和异常压缩结构。主表带 canonical 列键，语言只影响显示；日期可为 ISO 或 Excel 日期，代码保留文本及前导零。旧行 ID／行版本保留，新行 ID 空、版本0；停用用 enabled=0。文件漏行不删除，已停产机型仍可以启用。存在任何行错误的预览不产生可执行摘要，不能部分应用。

每次正式写入重查当前身份、会话、门店授权和指定管理账号，核对 Origin、两种身份 header、目录版本、逐行版本、摘要和请求 UUID。全局控制行锁、原有可重试 Serializable 事务、before／after 历史和幂等回执保证一次提交。撤销是将某版本的逆向差异先预览，再按当前版本确认，不删除历史。未知提交结果保留原请求重试，不能假报成功。身份变化锁住／清空旧目录草稿，低层请求合并仅限同时在途请求，不持久缓存管理权限。

`data/device-catalog/catalog.json` 是首次收集的部署种子和本地预览资料，不在每次部署时覆盖正式目录。来源与三语覆盖／缺漏分表保存。收集脚本只列官方明确存在的型号，不把抓取或文档日期当成机型发布日期，不把产品目录当作销量排名；部分官网无法直接抓取的范围应在覆盖中说明。后续增减通过正式目录／导出最新 Excel 完成。旧商品、客户维修、销售与签名快照不回填、不重写；打印继续读取当时保存的品牌型号原文。
