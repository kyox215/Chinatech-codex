## 本次修复

`MoneyKeypadInput` 在启用虚拟键盘时使用按钮作为入口，但没有实体键盘处理，所以点击金额框后直接打字没有效果。

## 建议整改与验收

1. O-01/O-02：用单一事务维护订单财务、事件与审计，以分类账为已收款权威。报价低于已收金额应明确拒绝；更正/退款采用有原因、幂等和审计的既有或独立流程。故障注入证明整体回滚或同 ID 安全重放。涉及资金规则与数据库事务，需要单独冻结整改合同。
2. O-03：以数据库操作表作为唯一幂等来源；比较店铺、操作人、操作 ID 与请求摘要。覆盖同 ID 同摘要、不同摘要、不同操作人、缺少 ID 和重试。
3. O-04：共同辅助函数同时过滤转场与目标状态的启用标志；任务页和批量菜单加入停用目标测试。
4. O-05/O-06：明确部分成功语义，保留失败项选择，列出逐项原因和重试入口；整体失败有安全本地化提示。验证网络拒绝、403/409、混合保管/审批、重入和并发冲突。
