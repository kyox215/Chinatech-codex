# 设置中心操作指南

这份指南说明当前本地验证版本的设置中心如何使用，以及哪些高风险功能仍未获准在生产环境开放。页面入口是 `/settings`。本指南不是生产启用证明；实际权限以页面返回的服务端能力为准。

## 1. 进入与导航

- `/settings` 默认打开简化后的常用设置入口。桌面左侧只显示当前账号可访问的核心项；低频能力收在默认折叠的“更多设置”中。
- 核心入口固定为店铺资料、员工与权限、业务默认值、客户消息与打印。账号仍可通过 `/settings?section=account` 兼容打开，但日常入口在账号菜单的“个人中心”（`/account`）。
- 供应商、客户 iPad、状态流、AI 使用量和工单数据按服务端 capability 出现在“更多设置”中；不可访问项不显示，语义只读项仍可查看。
- 子功能仍可直接打开，例如 `/settings?section=store`。无效参数会安全回到总览。
- 手机端在子页面顶部使用“返回设置总览”；桌面端使用左侧设置导航。
- 页面不会用前端角色名称自行猜权限；导航只根据服务端能力渲染可访问入口。

## 2. 共同操作规则

### 当前店铺

所有店铺业务设置只属于当前活动店铺。切换店铺后，旧店铺的草稿、一次性代码、预览和迟到响应不能出现在新店铺。

### 保存和离开

- 店铺、通知与打印、默认规则使用各自独立的草稿和保存状态。
- 修改后离开子功能、切换店铺、退出登录或使用浏览器历史时，会先出现未保存提示。
- “保存并继续”只会保存真正支持保存的草稿。Kiosk 退回原因可暂存到当前浏览器的 `sessionStorage`，但不会写入后端；状态流草稿和工单数据文件没有通用保存动作。
- 浏览器硬刷新或关闭标签页只能使用浏览器原生离开提醒，无法显示应用内三选一窗口。
- 普通设置草稿只保存在当前页面内；离线、硬刷新或关闭标签页后不保证恢复。

### 并发冲突

店铺、通知与默认规则保存使用版本校验。若另一窗口已经更新，页面会保留本地内容并提示冲突；请先查看服务器新版本，再选择重整草稿或放弃本地修改。不要反复点击保存覆盖他人修改。

### 权限与错误

- `只读`：可以查看语义化内容，但不会显示可误操作的禁用表单。
- `无法打开`：当前账号没有该业务权限，页面不会先读取相关业务数据。
- `无法确认权限`：店铺上下文或权限读取失败，请重新加载；不要把它当作没有数据。
- 操作失败会保留仍可恢复的草稿或预览。先阅读页面内持续显示的错误，再决定重试、修正或放弃。

## 3. 九个子功能

### 3.1 账号

用途：查看登录邮箱、验证状态、账号性质、当前店铺角色，并修改自己的显示名称。

操作：

1. 修改显示名称并使用账号区自己的保存操作。
2. 需要改邮箱、密码或联系手机号时，进入 `/account` 的安全流程；设置中心不会复制认证表单。
3. 显示名称草稿与店铺业务设置相互独立。

限制：所有已登录用户只能修改自己的显示名称，不能在此修改他人账号或店铺角色。

### 3.2 员工

用途：查看成员、邀请、待处理加入申请，以及在服务端允许时管理角色、额外权限、停用和恢复。

安全操作：

1. 先确认员工姓名、状态和当前角色。
2. 角色与额外权限可在同一编辑器查看，但不是一个原子保存。若角色变化，先只保存角色；刷新后再处理仍适用的额外权限。
3. 停用、恢复、批准、拒绝等危险动作必须经过确认，并等待当前请求完成。停用会撤销额外授权，恢复后不会自动还原旧授权。
4. 邀请码或邀请链接是短期敏感值，只在受控渠道交付；切换店铺或生成新值后，旧值不能继续显示。
5. 输入邮箱只生成邀请记录，不会自动发送邀请邮件；恢复成员也不会自动恢复此前的额外权限。

生产限制：员工角色/权限生产写入仍等待数据库 RPC、CAS、事务和审计验证。未完成发布门禁前，不把本地演示结果当作生产可用证明。

### 3.3 店铺

用途：查看或编辑当前店铺名称、地址、电话、WhatsApp 等基础业务资料，并检查客户输出状态。

操作：

1. 从应用侧边栏切换当前店铺；设置页不再重复显示工作区切换器。
2. 首屏只填写显示名称、邮箱、电话、WhatsApp 和打印地址；客户门户域名位于“更多选项”。修改后保存当前店铺分组。
3. “管理店铺与安全”默认折叠，只有按现有 Owner/capability 控制的账号才可使用重命名、创建、关闭或删除等管理组件。
4. 若客户消息或打印被资料缺失阻止，页面只显示一条可行动警告；补齐资料后再保存并回原流程“重新检查资料”。
5. 店铺邮箱、电话和 WhatsApp 至少填写一项；客户输出仍可能要求更完整的店铺身份资料。

限制：创建新店铺沿用现有已登录且邮箱已验证策略。新店铺不会复制旧店铺的数据或权限。是否改成平台审批属于 Owner 决策，不在此指南中承诺。

### 3.4 供应商

用途：查看配件或外修来源，新建/编辑名称、简称、联系人、电话、邮箱、网址和备注，并执行快捷联系。

操作：

1. 新建或编辑前核对当前店铺。
2. 邮箱必须有效，网址只接受 HTTP(S)，简称最多 32 个字符。
3. 归档前需要确认。当前 API 没有恢复归档入口，因此页面不会显示虚假的恢复按钮。

权限：有读取能力的账号可查看；只有服务端授予供应商管理能力的账号可新建、编辑或归档。

### 3.5 客户 iPad

用途：管理 Kiosk 设备配对、查看客户提交、接受资料、退回补充和撤销设备。

安全操作：

1. 配对码只显示一次、绑定店铺并在 15 分钟后过期；系统不会自动通过短信或邮件发送。它是敏感值，不截图外传、不写入备注或聊天记录。
2. 审核时按页面显示的提交版本操作；内容已经变化时，接受/退回会被拒绝并要求重新读取。
3. 退回原因草稿绑定店铺、会话和提交版本；成功接受/退回后会被消费。
4. 撤销或稳定未授权会清除浏览器中的 Kiosk 客户资料；普通网络故障保留尚未提交的表单，便于恢复。
5. 退回原因最多 240 个字符。签名画布只形成应用内证据，不代表高级或合格电子签名。

生产限制：所有 Supabase-backed Kiosk 流程必须同时满足两个默认关闭开关。事务 RPC、Storage 补偿、限流、令牌策略、保留期/GDPR 和数据库约束门禁未通过前，不得真实采集或审核客户数据。

### 3.6 默认规则

用途：设置快速接单模式、新维修单质保和新库存商品质保默认值，并预览恢复默认值。维修成本、币种、采购和历史回填位于默认折叠的“财务与成本”区域。

规则：

- `0` 表示无质保；正整数表示月数。库存默认值必须在 `0–120` 之间，空值会被判为校验错误。
- 恢复默认值只修改当前草稿，仍需正常保存，不会立即写入数据库。
- 新默认值只影响之后创建并未显式覆盖的对象，不会重写既有工单或库存历史。
- 库存入库会保存当时解析后的质保快照；以后销售不会重新读取新设置。
- SeaTable 历史导入不继承当前库存默认质保，必须按导入合同单独处理。

### 3.7 状态流

用途：查看和本地编辑工单状态、顺序、默认状态和允许的流转关系，并检查变更摘要。

操作：

1. 在状态编辑器中修改本地草稿；编辑过程不会调用旧的四个即时写入接口。
2. 检查重复代码、默认状态、启用状态和流转错误。
3. 打开变更摘要核对新增、重命名、排序、默认和流转影响。

生产限制：“应用状态流”仍锁定。必须先有 revision/CAS、一个店铺范围事务 RPC、已有工单兼容预检和原子审计/outbox；不得把旧接口按顺序调用伪装成一次原子应用。

### 3.8 通知与打印

用途：编辑客户消息签名和打印页脚，并按需预览当前输出身份。

操作：

1. 修改只影响当前通知分组草稿；隐藏的店铺或规则草稿不会污染预览。
2. 保存后，客户消息/打印继续使用活动店铺的已保存资料。
3. 通过“预览客户消息”或“预览打印资料”按钮打开对应预览；关闭对话框不会改变草稿或保存状态。
4. 消息模板在 `/messages` 管理。只有服务端授予模板读取能力时才显示可用链接。

限制：设置中心不发送测试 WhatsApp/SMS，也不复制完整消息模板编辑器。

### 3.9 工单数据

用途：在单独批准的环境中下载空白模板、导出安全工单字段、导出客户统计、上传 XLSX 并先生成预览。

安全流程：

1. 确认当前店铺，选择不超过 4 MB 的 `.xlsx` 和导入模式。
2. 生成服务端预览。预览本身不修改工单。
3. 核对店铺、模式、文件、有效期、工单号、行号和变更字段。页面初始显示 10 行、最多展开前 100 行；完整内容使用预览报告。
4. 修正所有错误行后重新生成预览。过期预览和已处理批次不能重复应用。
5. 在获得生产 Apply 批准后，仍需勾选店铺确认并通过第二次确认。部分完成时下载完整错误报告，不重复提交同一批次。
6. “最近批次”按需读取当前店铺最近 20 个脱敏摘要，不返回工作簿、客户字段或字段前后值。

生产限制：只有精确配置 `ORDER_DATA_EXPORT_ENABLED=1` 才开放导出/预览/历史；Apply 还需要 `ORDER_DATA_APPLY_ENABLED=1`。当前两项均应保持关闭。24 小时到期只表示不能应用，不等于 PII 已按时删除；清理调度、流式请求体上限、限流、原子暂存、正常建单流程/质保审计一致性和最大事务证明仍是硬门禁。导入回滚目前不向操作员开放；新建成功的工单行也不会由页面自动删除。

## 4. 常见恢复方式

| 情况                 | 正确处理                                                     |
| -------------------- | ------------------------------------------------------------ |
| 保存显示版本冲突     | 保留本地内容，读取服务器新版本，选择重整或放弃；不要盲目覆盖 |
| 离开时出现未保存提示 | 选择保存、放弃或取消；先看提示列出的具体分组                 |
| 权限无法确认         | 重新加载当前店铺上下文；持续失败时交给管理员，不反复提交     |
| 客户输出缺店铺资料   | 使用业务对话框的准确设置入口，补齐后回原流程重新检查         |
| Kiosk 稳定未授权     | 重新配对；不要尝试恢复旧令牌或旧客户资料                     |
| Kiosk 暂时断网       | 保留当前未提交表单，网络恢复后重试                           |
| 状态流 Apply 锁定    | 这是发布门禁，不是浏览器故障；不要调用旧接口绕过             |
| 工单数据预览过期     | 清除文件后重新选择并生成新预览                               |
| 工单数据部分完成     | 下载完整错误报告，核对已成功与未成功行；不要重复应用同一批次 |
