# AI 协作说明（兼容入口）

状态：自2026-09-15起不再作为每项任务必读制度。当前规则以 [AGENTS.md](../AGENTS.md) 为准。

原600行部门设计已逐字移入 [历史快照](../docs/archive/governance-20260915/department-design.snapshot.md.txt)。保留此路径供旧引用与工具兼容；不要求模拟公司组织、开启全部部门或维护重复工作包。

- `decision_owner: Integration Lead`：主线程理解目标、协调、验收和汇报；跨会话集成仍须有效lease。
- 子代理用于独立、可验证的工作，不是固定组织岗位；默认只读，授权写入时明确文件所有权。
- 子代理不得直接向用户请求扩大权限；不提交、发布、处理秘密或执行生产动作。
- 需要详细派单时可按需参考 [任务包](../.agents/task-package-template.md) 与 [.agents/decision-flow.md](../.agents/decision-flow.md)，无需每任务复制模板。
- 产品、权限、数据、UI和发布安全边界由根规则与对应业务声明维护；部门文件不再复制另一套。

规则变化后运行 `npm run agents:check`。历史文档中的模型和并发数字不覆盖当前根规则。
