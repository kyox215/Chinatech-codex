# Native Office development

The Office Assistant native client, tests, signing tools and build workflow are maintained in the authorized private `kyox215/ChinaTech-OfficeAssistant` repository. This public website repository retains download metadata, website admission APIs and usage instructions. Existing public release artifacts and Git history are retained. Future native source archives, symbols and internal build logs are not published here.

Public and private CI must both pass before a new native version is released. A private build or synthetic test does not establish real Windows Office acceptance.
