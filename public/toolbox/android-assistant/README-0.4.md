# ChinaTech 手机助手 0.4.0-alpha

Android 8 及以上。两部手机安装相同的 0.4 版本；可直接覆盖本站 0.3，不需卸载，也不会删除旧机原件或接收目录。更新前先结束当前传输。

1. 旧机扫描已授权资料并选择项目。新机选择接收目录与恢复范围（媒体、通讯录、日历、APP）。
2. 新机创建热点二维码；旧机扫码并核对两端信息。自动连接失败时使用手动热点或同一 Wi-Fi。
3. 正常传输在数据流中核对长度和 SHA256，写入、关闭成功后即显示“新机已保存”，不会再整文件重读。断线恢复才会重新打开并核对已有文件；未完成文件从头传输。
4. 传输完成后，媒体自动导入 ChinaTech 目录；通讯录和日历需授予写入权限并选择目标；APP 由系统逐个确认安装。私有 APP 数据、登录、聊天、短信和通话记录不会迁移。

# ChinaTech Phone Assistant 0.4.0-alpha

Android 8 or later. Install the same 0.4 version on both phones. It can update this site’s 0.3 directly without uninstalling or deleting originals or the receiving folder. End any active transfer first.

1. On the old phone, scan and select authorized data. On the new phone, choose the receiving folder and restoration scope: media, contacts, calendar and apps.
2. Create the hotspot QR on the new phone, then scan it and check both ends on the old phone. Use a manual hotspot or the same Wi-Fi if automatic connection fails.
3. Normal transfer verifies length and SHA256 in the stream. After a successful write and close, it shows “Saved on the new phone” without rereading the whole file. Only recovery after disconnection reopens and verifies existing files; incomplete files restart.
4. After transfer, media imports automatically to the ChinaTech folder. Contacts and calendar need write permission and a selected destination. The system confirms each app installation. Private app data, sign-ins, chats, SMS and call history do not migrate.

# ChinaTech Assistente telefono 0.4.0-alpha

Android 8 o successivo. Installa la stessa versione 0.4 su entrambi i telefoni. Può aggiornare direttamente la 0.3 di questo sito senza disinstallare né eliminare originali o cartella di ricezione. Termina prima qualsiasi trasferimento attivo.

1. Sul vecchio telefono scansiona e seleziona i dati autorizzati. Sul nuovo scegli cartella di ricezione e ambito di ripristino: media, contatti, calendario e APP.
2. Crea il QR dell’hotspot sul nuovo telefono, poi scansionalo e controlla entrambi i lati sul vecchio. Se la connessione automatica fallisce, usa hotspot manuale o la stessa Wi-Fi.
3. Il trasferimento normale verifica lunghezza e SHA256 nel flusso. Dopo scrittura e chiusura riuscite appare “Salvato sul nuovo telefono”, senza rileggere tutto il file. Solo il recupero dopo disconnessione riapre e verifica i file esistenti; quelli incompleti ripartono.
4. Dopo il trasferimento, i media vengono importati automaticamente nella cartella ChinaTech. Contatti e calendario richiedono permesso di scrittura e destinazione selezionata. Il sistema conferma ogni installazione APP. Dati privati delle APP, accessi, chat, SMS e cronologia chiamate non migrano.
