# Memory Delta

## Candidate Lesson

For RepairDesk order detail text-edit Sheets, repair quote items should be transformed through pure helpers before UI use. This allows dedupe and tests without coupling UI behavior to mutation or API code.

For mobile RepairOS bottom Sheets, keep command footers outside the scroll body and use compact counters in the header when the user needs high-density editing. This avoids pushing primary actions below the fold while preserving source-item context.

## Not Long-Term Yet

This is task-specific unless the same helper pattern is reused by new order, print, or customer communication flows.
