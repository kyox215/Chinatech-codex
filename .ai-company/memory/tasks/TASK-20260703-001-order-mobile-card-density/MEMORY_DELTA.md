# Memory Delta

## Candidates

- Mobile order list cards should prioritize customer, phone, device/fault, technician, payment amount, and next action. Order number and normal order type can be hidden from the mobile card body when the owner asks for high-density scanning.
- For mobile order cards, keep money grouped on the right side instead of splitting total/balance across a full-width row.
- Use five compact stage cells on mobile list cards rather than a short partial rail; it reads cleaner while staying dense.
