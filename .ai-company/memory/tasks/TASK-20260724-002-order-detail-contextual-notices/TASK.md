# TASK-20260724-002 — 订单详情提示上下文化

Status: conditional
Owner: RepairDesk Integration Lead
Risk / autonomy: R2 / L2
Task tier: T2

## 目标

把桌面与平板订单详情顶部占空间的大提示改为紧凑、就近的上下文入口，同时保留现有权限、确认、审计与 mutation 逻辑；手机端现有结构不变。

## 范围

- 已结束/已作废状态进入订单 Hero 标题区。
- 纠正、重新打开保留为紧凑操作；安全作废降级到更多菜单。
- 设备保管提示与操作进入“关键信息”卡。
- 店铺输出身份或二维码配置阻塞进入打印按钮的上下文弹层。
- 更新相关组件测试、响应式验证与截图证据。

## 非范围

- 不改变订单状态机、权限、API、数据库或审计逻辑。
- 不改变手机端订单详情结构。
- 不提交、推送或部署。

## 验收标准

1. 桌面/平板详情顶部不再堆叠三块大提示。
2. 结束状态及允许的纠正/重开/作废路径仍可发现且保持原确认流程。
3. 设备保管状态、冲突说明和可用操作在关键信息区域完整可见。
4. 打印不可用时，点击打印入口可查看原因并执行现有恢复动作。
5. 手机端原有顶部提示与设备保管结构无视觉/交互改动。
6. 目标测试、typecheck、lint 通过；桌面、平板、手机无横向溢出。

代码、测试与生产构建已经通过；真实浏览器截图和视口溢出读数因本地预览被浏览器安全策略阻断，需在可访问本地预览的浏览器会话中补验后才能改为 closed。
