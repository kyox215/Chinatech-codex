# Memory Delta — TASK-20260619-007

## Candidate reusable learning

- For the new order workspace, use:
  - two columns at 1024px,
  - compact three columns at 1280px,
  - expanded three columns at 1536px+.
- The actual desktop content width is reduced by the app sidebar; do not size dense workspaces solely from viewport width.
- Keep quotation/service controls as their own column for faster order intake; avoid using the third column only for read-only summaries.

## Long-term memory recommendation

Consider adding this as a frontend/design memory if future order intake or dialog work repeats the same breakpoint mistake.
