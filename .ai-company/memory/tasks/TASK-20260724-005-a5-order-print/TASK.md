# Task

## Owner goal

保持当前维修工单的字段、顺序、文案、二维码位置和左右两栏布局不变，提供可靠的 A5 横向直接打印与 A4 竖向上半页裁切打印；长内容必须在同一张 A5 票据内换行并受控缩放，不得生成第二张票据。完成后推送 `main` 并部署生产。

## Acceptance contract

1. A5 模式的 CSS 页面严格为 210×148mm 横向；A4 裁切模式严格为 210×297mm 竖向，原尺寸 A5 票据位于上半页，148.5mm 处有裁切线，下半页留白。
2. 两种模式复用同一个工单内容组件；字段、顺序、两栏结构、二维码和质保文案不发生业务层变更。
3. 单张工单只产生一页；长文本先换行、再按完整票据等比缩放，不截断、不省略、不拆页。
4. 所有工单业务状态继续允许打印，且每张工单含固定客户状态二维码。
5. 打印前允许选择 A5 或 A4 对半，记住最近一次选择；Windows、macOS、iPhone/iPad 使用相同模式合同。
6. 直接浏览器打印不得把内部工单详情 UI 当作客户票据输出。
7. 定向单测、类型检查、构建、PDF 页数/尺寸和可视截图验证通过。

## Change contract

- 仅修改打印介质、纸张模式选择、单页适配、打印生命周期、测试和声明文档。
- 不修改订单数据、二维码身份、权限、金额算法或客户公开进度逻辑。
- 主线程是唯一写入者；部门子代理只读复核。

## Rollback

回退本任务应用提交即可恢复旧打印实现；不含数据库迁移和不可逆数据操作。
