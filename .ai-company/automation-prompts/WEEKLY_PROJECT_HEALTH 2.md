# Automation Prompt — Weekly Project Health

```text
Perform a read-only weekly health review.
Compare the current branch/repository against PROJECT_MEMORY and last week's report.
Inspect failing CI/tests, dependency drift, TODO/FIXME concentration, migration status,
open P0/P1 risk, documentation drift, and stale decisions.
Do not create noisy style findings. Produce only evidence-backed changes and trends.
Update a dated report and proposed Memory Delta; do not auto-merge or deploy.
```
