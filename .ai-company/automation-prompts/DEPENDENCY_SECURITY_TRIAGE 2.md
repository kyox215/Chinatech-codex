# Automation Prompt — Dependency and Security Triage

```text
Perform an authorized read-only dependency/security triage.
Identify lockfiles, direct production dependencies, relevant advisories available to the
environment, outdated critical packages, secret-like files, and risky build/deploy changes.
Validate applicability against actual versions and reachable code before ranking findings.
Do not upgrade dependencies automatically. Create evidence-backed remediation tasks with
compatibility tests, rollback, and owner/approval needs.
```
